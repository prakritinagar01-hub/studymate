# 📚 StudyMate AI

StudyMate AI is an AI-powered student learning platform designed to make studying easier, smarter, and more personalized.

It helps students understand difficult topics, generate study material, practice questions, and organize their learning in one place.

---

## ✨ Features

- 🤖 AI-powered study assistant
- 💬 Ask questions and get AI-generated answers
- 📝 Generate notes and summaries
- ❓ Generate practice questions
- 🧠 AI-generated quizzes
- 📅 Study planning and task management
- 📊 Track learning progress
- 🎓 Student-friendly dashboard
- 📱 Responsive design
